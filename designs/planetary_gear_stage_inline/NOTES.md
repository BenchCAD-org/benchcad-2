# planetary_gear_stage_inline

This is issue 182's core single-stage planetary gear train, deliberately shown
without an external enclosure so all mesh and carrier features remain visible.

| body | count | reason |
|---|---:|---|
| housing_ring_gear | 1 | thin annular ring with internal teeth |
| sun_shaft | 1 | sun gear is integral with input shaft |
| planet_gear | 3 | each planet turns independently on its pin |
| carrier_output | 1 | two discs, pins, output shaft, collar and key are rigid |

The PLE060 anchor uses 12 / 12 / 36 teeth: a three-planet, 4:1 stage.
Bearings, seals, motor adapters, clamp hubs, case bolts and the external
gearbox shell are intentionally omitted.
